# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.6.x   | :white_check_mark: |
| 1.5.x   | :white_check_mark: |
| < 1.5   | :x:                |

## Reporting a Vulnerability

Security is a foundational tenet of True MoA. If you discover a vulnerability, leak of sensitive reference material, or bypass of the fail-closed gate:

1. **Do not open a public issue.**
2. Report the vulnerability privately via [GitHub Security Advisories](https://github.com/sovergarden-dev/trueMoA/security/advisories/new) or contact the project maintainers directly.
3. Provide a detailed reproduction script, target Hermes version, and expected vs observed behavior.

We strive to acknowledge receipt within 48 hours and release patches in coordination with reporter disclosure windows.
